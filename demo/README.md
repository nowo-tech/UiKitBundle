# Ui Kit Bundle demos

| Demo | Port | Framework |
|------|------|-----------|
| [symfony8](symfony8/) | 8092 | Bootstrap 5 (`css_framework: bootstrap5`) |
| [symfony8-tailwind](symfony8-tailwind/) | 8093 | Tailwind (`css_framework: tailwind`) |

Both run with **FrankenPHP**. See [docs/DEMO-FRANKENPHP.md](../docs/DEMO-FRANKENPHP.md).

```bash
make -C demo up-symfony8
make -C demo up-symfony8-tailwind
```
